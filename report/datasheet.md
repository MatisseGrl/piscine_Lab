# Datasheet du dataset final

Sur le modèle de *Datasheets for Datasets* (Gebru et al. 2018).

## Motivation
Pourquoi ce dataset a été créé, par qui, pour quelle tâche.

## Composition
Ce que contient chaque instance, nombre d'instances et de tokens, part de chaque source, part de données synthétiques, données personnelles ou sensibles.

## Processus de collecte
Comment les données ont été obtenues, sur quelle période, avec quels outils.

## Prétraitement, nettoyage, étiquetage
Étapes du pipeline, seuils retenus et pourquoi, ce qui a été retiré.

## Usages
Usages prévus, usages déconseillés.

## Distribution
Licence, hash, lien Hugging Face le cas échéant.

## Maintenance
Qui maintient le dataset, comment le regénérer.
